# 前端开发指南

> 本文档介绍宠物领养平台前端项目的运行方式、目录结构和开发指南。

---

## 一、环境要求

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | 18.0+ | JavaScript 运行环境 |
| npm | 9.0+ | 包管理器（随 Node.js 安装） |
| 浏览器 | Chrome/Edge/Firefox 最新版 | 开发调试 |

### 检查环境

```bash
# 检查 Node.js 版本
node -v
# 期望输出: v18.x.x 或更高

# 检查 npm 版本
npm -v
# 期望输出: 9.x.x 或更高
```

## 二、快速启动

### 1. 进入前端目录

```bash
cd web
```

### 2. 安装依赖

```bash
npm install
```

首次安装可能需要几分钟，请耐心等待。

### 3. 启动开发服务器

```bash
npm run dev
```

### 4. 访问应用

启动成功后，在浏览器中访问：

```
http://localhost:3000
```

## 九、开发指南

### 9.1 添加新页面

1. 在 `src/pages/` 下创建页面组件：

```tsx
// src/pages/NewPage.tsx
export function NewPage() {
  return (
    <div className="container py-8">
      <h1 className="text-2xl font-bold">新页面</h1>
    </div>
  )
}
```

2. 在 `src/router/index.tsx` 中添加路由：

```tsx
import { NewPage } from '../pages/NewPage'

// 在 children 数组中添加
{ path: 'new-page', element: <NewPage /> }
```

### 9.2 调用API

使用 TanStack Query 进行数据请求：

```tsx
import { useQuery } from '@tanstack/react-query'
import { petApi } from '../lib/api'

function MyComponent() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['pets'],
    queryFn: () => petApi.list(),
  })

  if (isLoading) return <div>加载中...</div>
  if (error) return <div>加载失败</div>

  return <div>{/* 渲染数据 */}</div>
}
```

### 9.3 使用状态管理

```tsx
import { useAuthStore } from '../store/auth'

function MyComponent() {
  const { user, isAuthenticated, login, logout } = useAuthStore()

  return (
    <div>
      {isAuthenticated ? (
        <span>欢迎, {user?.username}</span>
      ) : (
        <button onClick={() => login(username, password)}>登录</button>
      )}
    </div>
  )
}
```

### 9.4 使用UI组件

```tsx
import { Button } from '../components/ui/button'
import { Card, CardHeader, CardTitle, CardContent } from '../components/ui/card'
import { Input } from '../components/ui/input'

function MyComponent() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>标题</CardTitle>
      </CardHeader>
      <CardContent>
        <Input placeholder="请输入..." />
        <Button>提交</Button>
      </CardContent>
    </Card>
  )
}
```

### 9.5 样式开发

使用 TailwindCSS 类名：

```tsx
<div className="container mx-auto py-8">
  <h1 className="text-2xl font-bold text-primary mb-4">标题</h1>
  <p className="text-muted-foreground">描述文字</p>
  <button className="bg-primary text-white px-4 py-2 rounded-md hover:bg-primary/90">
    按钮
  </button>
```

## 十、常见问题

### Q1: 启动报错 "port 3000 is already in use"

端口被占用，修改 `vite.config.ts`：

```typescript
export default defineConfig({
  server: {
    port: 3001, // 改为其他端口
  },
})
```

### Q2: API 请求失败

1. 确保后端服务已启动 (`go run cmd/server/main.go`)
2. 检查 `.env.development` 中的 API 地址配置
3. 检查浏览器控制台的网络请求

### Q3: 样式不生效

1. 确保已正确导入 TailwindCSS
2. 检查 `index.css` 是否包含 Tailwind 指令
3. 重启开发服务器

### Q4: 热更新不工作

1. 检查文件是否保存
2. 尝试重启开发服务器
3. 清除浏览器缓存

## 十一、生产部署

### 构建

```bash
npm run build
```

构建产物在 `dist/` 目录。

### 部署到 Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:8080;
    }
}
```
