# MySQL 8.4 数据库部署指南

## 📋 部署前准备

### 1. 环境要求
- ✅ MySQL 8.4 已安装
- ✅ 服务器已启动并可连接
- ✅ root 用户密码已知
- ✅ 防火墙已配置（开放 3306 端口）

### 2. 检查 MySQL 版本
```bash
mysql --version
# 应显示: mysql  Ver 8.4.x
```

### 3. 测试 root 连接
```bash
mysql -u root -p
```

## 🚀 部署步骤

### 方式一：一键部署（推荐）

#### 1. 上传脚本到服务器
```bash
# 将以下文件上传到服务器 /opt/pet-adoption/scripts/ 目录
01_create_user_and_database.sql
02_create_tables.sql
03_init_data.sql
```

#### 2. 执行一键部署
```bash
cd /opt/pet-adoption/scripts

# 步骤1: 创建用户和数据库（需要root密码）
mysql -u root -p < 01_create_user_and_database.sql

# 步骤2: 创建数据表（使用新创建的pet_admin用户）
mysql -u pet_admin -p pet_adoption < 02_create_tables.sql

# 步骤3: 插入初始数据
mysql -u pet_admin -p pet_adoption < 03_init_data.sql
```

#### 3. 验证部署
```bash
mysql -u pet_admin -p pet_adoption -e "SHOW TABLES;"
```

### 方式二：分步执行（详细）

#### 步骤 1: 创建数据库用户

**1.1 登录 MySQL**
```bash
mysql -u root -p
```

**1.2 执行创建脚本**
```sql
-- 创建数据库
CREATE DATABASE pet_adoption 
    CHARACTER SET utf8mb4 
    COLLATE utf8mb4_unicode_ci;

-- 创建应用用户
CREATE USER 'pet_admin'@'%' IDENTIFIED BY 'Pet@Admin#2024!Secure';
CREATE USER 'pet_admin'@'localhost' IDENTIFIED BY 'Pet@Admin#2024!Secure';

-- 授权
GRANT ALL PRIVILEGES ON pet_adoption.* TO 'pet_admin'@'%';
GRANT ALL PRIVILEGES ON pet_adoption.* TO 'pet_admin'@'localhost';

-- 创建只读用户（可选）
CREATE USER 'pet_readonly'@'%' IDENTIFIED BY 'Pet@ReadOnly#2024';
GRANT SELECT ON pet_adoption.* TO 'pet_readonly'@'%';

-- 刷新权限
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

**1.3 测试新用户**
```bash
mysql -u pet_admin -p pet_adoption
# 输入密码: Pet@Admin#2024!Secure
```

#### 步骤 2: 创建数据表

**2.1 使用新用户登录**
```bash
mysql -u pet_admin -p pet_adoption
```

**2.2 执行建表脚本**
```sql
SOURCE /opt/pet-adoption/scripts/02_create_tables.sql;
```

**2.3 验证表创建**
```sql
SHOW TABLES;
-- 应显示10个表

DESCRIBE users;
-- 查看用户表结构
```

#### 步骤 3: 插入初始数据

**3.1 执行初始化脚本**
```sql
SOURCE /opt/pet-adoption/scripts/03_init_data.sql;
```

**3.2 验证数据**
```sql
SELECT * FROM users WHERE role = 'admin';
-- 应显示管理员账户
```

## 🔐 安全配置（重要！）

### 1. 修改默认密码

**立即修改应用用户密码**
```sql
-- 登录MySQL
mysql -u root -p

-- 修改密码（请设置复杂密码）
ALTER USER 'pet_admin'@'%' IDENTIFIED BY 'YourStrongPassword@2024';
ALTER USER 'pet_admin'@'localhost' IDENTIFIED BY 'YourStrongPassword@2024';

FLUSH PRIVILEGES;
```

**修改配置文件**
```yaml
# config/config.yaml
database:
  mysql:
    username: "pet_admin"
    password: "YourStrongPassword@2024"  # 修改为新密码
```

### 2. 限制远程访问（推荐）

如果只允许本地应用访问：
```sql
-- 删除远程用户
DROP USER 'pet_admin'@'%';

-- 只保留本地用户
-- pet_admin@localhost 已创建，无需额外操作
```

### 3. 启用密码策略（可选）

```sql
-- 设置密码90天过期
ALTER USER 'pet_admin'@'%' PASSWORD EXPIRE INTERVAL 90 DAY;

-- 设置密码复杂度要求
SET GLOBAL validate_password.policy = STRONG;
SET GLOBAL validate_password.length = 12;
```

### 4. 配置 SSL 连接（生产环境推荐）

```sql
-- 检查SSL状态
SHOW VARIABLES LIKE '%ssl%';

-- 要求SSL连接
ALTER USER 'pet_admin'@'%' REQUIRE SSL;
```

## 🛠️ 常用维护命令

### 查看数据库状态
```sql
-- 数据库大小
SELECT 
    table_schema AS '数据库',
    ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS '大小(MB)'
FROM information_schema.TABLES 
WHERE table_schema = 'pet_adoption'
GROUP BY table_schema;

-- 表大小统计
SELECT 
    table_name AS '表名',
    table_rows AS '行数',
    ROUND(data_length / 1024 / 1024, 2) AS '数据大小(MB)',
    ROUND(index_length / 1024 / 1024, 2) AS '索引大小(MB)'
FROM information_schema.TABLES
WHERE table_schema = 'pet_adoption'
ORDER BY data_length DESC;

-- 查看连接数
SHOW PROCESSLIST;

-- 查看当前用户
SELECT USER(), DATABASE();
```

### 备份数据库
```bash
# 完整备份
mysqldump -u pet_admin -p pet_adoption > pet_adoption_backup_$(date +%Y%m%d).sql

# 只备份结构
mysqldump -u pet_admin -p --no-data pet_adoption > pet_adoption_schema.sql

# 只备份数据
mysqldump -u pet_admin -p --no-create-info pet_adoption > pet_adoption_data.sql

# 备份单个表
```

### 恢复数据库

## 🔥 性能优化建议

### 1. 配置 MySQL 参数

编辑 `/etc/mysql/my.cnf` 或 `/etc/my.cnf`:

```ini
[mysqld]
# 字符集
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci

# InnoDB 缓冲池（建议设置为服务器内存的 70-80%）
innodb_buffer_pool_size = 2G

# 连接数
max_connections = 500

# 查询缓存（MySQL 8.0已移除，忽略）
# query_cache_size = 64M

# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2

# 二进制日志（用于复制和恢复）
log_bin = /var/log/mysql/mysql-bin.log
binlog_expire_logs_seconds = 864000  # 10天

# 其他优化
innodb_flush_log_at_trx_commit = 2
innodb_log_file_size = 256M
```

重启 MySQL:
```bash
systemctl restart mysql
```

### 2. 创建定时备份

```bash
# 创建备份脚本
cat > /opt/pet-adoption/backup.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/opt/pet-adoption/backups"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

mysqldump -u pet_admin -p'YourPassword' pet_adoption | gzip > $BACKUP_DIR/pet_adoption_$DATE.sql.gz

# 删除7天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete
EOF

chmod +x /opt/pet-adoption/backup.sh

# 添加定时任务（每天凌晨2点备份）
crontab -e
# 添加: 0 2 * * * /opt/pet-adoption/backup.sh
```

### 3. 监控慢查询

```sql
-- 查看慢查询日志状态
SHOW VARIABLES LIKE 'slow_query%';

-- 查看慢查询数量
SHOW GLOBAL STATUS LIKE 'Slow_queries';
```

## ❓ 常见问题

### Q1: 连接被拒绝
```bash
ERROR 2003 (HY000): Can't connect to MySQL server on 'host'
```
**解决**:
1. 检查防火墙: `ufw allow 3306`
2. 检查 MySQL 监听: `netstat -tlnp | grep 3306`
3. 检查 bind-address: 修改 my.cnf 设置 `bind-address = 0.0.0.0`

### Q2: 权限不足
```bash
ERROR 1045 (28000): Access denied for user
```
**解决**:
```sql
-- 重新授权
GRANT ALL PRIVILEGES ON pet_adoption.* TO 'pet_admin'@'%';
FLUSH PRIVILEGES;
```

### Q3: 字符集问题
```bash
Incorrect string value
```
**解决**:
```sql
-- 检查字符集
SHOW VARIABLES LIKE 'character%';

-- 修改表字符集
ALTER TABLE users CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Q4: 外键约束错误
```bash
Cannot add or update a child row: a foreign key constraint fails
```
**解决**:
- 确保父表记录存在
- 检查外键字段类型匹配
- 必要时临时禁用: `SET FOREIGN_KEY_CHECKS=0;`
