# 🐾 宠爱有家 - 宠物领养平台

让每一只流浪动物都能找到温暖的家。

## 📋 功能介绍

宠爱有家是一个连接宠物救助机构与领养者的综合性在线平台，提供以下核心功能：

- 🐕 **宠物发布** - 发布待领养宠物信息
- 📝 **领养申请** - 在线提交领养申请
- 🏢 **机构入驻** - 救助机构认证入驻
- 💬 **社区互动** - 分享养宠心得与故事
- ❤️ **爱心捐赠** - 为流浪动物献爱心

---

## 🚀 快速开始

### 1. 注册账号

1. 访问应用首页
2. 点击右上角「立即注册」
3. 填写用户名、邮箱和密码
4. 完成注册后自动登录

### 2. 浏览宠物

1. 点击导航栏「找宠物」
2. 使用筛选条件查找心仪宠物：
   - 物种：猫咪 / 狗狗 / 其他
   - 性别：公 / 母
   - 年龄、体型等
3. 点击宠物卡片查看详情

### 3. 提交领养申请

1. 在宠物详情页点击「申请领养」
2. 填写个人信息：
   - 基本信息（姓名、电话、地址）
   - 家庭情况（住房类型、家庭成员）
   - 养宠经验
   - 领养原因
3. 提交申请，等待审核

---

## 📤 发布宠物信息

适用于救助机构或个人发布待领养宠物。

### 发布步骤

1. 登录后点击用户菜单 →「我的宠物」
2. 点击「发布宠物」按钮
3. 填写宠物信息：

| 字段 | 说明 |
|------|------|
| 宠物名称 | 给它起个名字 |
| 宠物类型 | 猫咪 / 狗狗 / 其他 |
| 品种 | 如：金毛、英短等 |
| 性别 | 公 / 母 |
| 年龄（月） | 宠物月龄 |
| 体型 | 小型 / 中型 / 大型 |
| 毛色 | 毛色描述 |
| 体重 | 单位：kg |

4. 填写健康信息：
   - 是否已接种疫苗
   - 是否已绝育
   - 健康状况说明

5. 上传宠物照片（建议多角度）
6. 填写宠物性格描述
7. 提交发布，等待审核通过

## 🏢 机构入驻

救助机构可申请入驻，获得认证标识。

1. 登录后点击用户菜单 →「我的机构」
2. 点击「申请入驻」
3. 填写机构信息：
   - 机构名称、联系方式
   - 营业执照号
   - 机构介绍
   - 上传证明材料
4. 提交申请，等待审核

## ❤️ 爱心捐赠

为流浪动物献出爱心。

1. 点击导航栏「爱心捐赠」
2. 选择捐赠方式：
   - 定向捐赠（指定机构或宠物）

## � 管理员功能

> 管理员账号需要在数据库中将用户的 `role` 字段设置为 `admin`

### 宠物审核

管理员可以审核用户发布的宠物信息：

1. 访问 `/api/v1/pets/pending` 获取待审核列表
2. 审核通过：`PUT /api/v1/pets/{id}/approve`
3. 拒绝发布：`PUT /api/v1/pets/{id}/reject`

### 领养申请审核

管理员可以处理领养申请：

1. 访问 `/api/v1/adoptions/applications/pending` 获取待审核申请
2. 审核申请：`PUT /api/v1/adoptions/applications/{id}/review`

### 机构入驻审核

管理员可以审核机构入驻申请：

1. 更新机构状态：`PUT /api/v1/organizations/{id}/status`
   - `approved` - 通过
   - `rejected` - 拒绝

### 设置管理员账号

在 MySQL 中执行：

```sql
UPDATE users SET role = 'admin' WHERE username = '您的用户名';
```
