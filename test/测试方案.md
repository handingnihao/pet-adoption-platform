## 1. 测试策略

### 1.1 测试金字塔

```
        /\

     /      \  集成测试 (20%)

   /          \  单元测试 (70%)
  /__________\

### 1.2 测试类型

| 测试类型 | 占比 | 目标 | 工具 |
|---------|------|------|------|
| 单元测试 | 70% | 测试单个函数/方法 | Go testing, testify |

func TestUserService_Register(t *testing.T) {
    // 使用Mock
    mockDAO := new(MockUserDAO)
    mockCache := new(MockRedisClient)
    service := &service.UserService{
        userDAO: mockDAO,
        cache:   mockCache,
    }
    
    // 测试用例
    tests := []struct {
        name    string
        req     *model.UserRegisterRequest
        wantErr error
    }{
        {
            name: "正常注册",
            req: &model.UserRegisterRequest{
                Username: "newuser",
                Password: "Test@123456",
                Phone:    "13800138000",
                Email:    "new@example.com",
            },
            wantErr: nil,
        },
        {
            name: "用户名已存在",
            req: &model.UserRegisterRequest{
                Username: "existuser",
                Password: "Test@123456",
                Phone:    "13800138001",
                Email:    "new@example.com",
            },
            wantErr: service.ErrUserExists,
        },
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // 设置Mock期望
            if tt.wantErr == service.ErrUserExists {
                mockDAO.On("ExistsByUsername", tt.req.Username).Return(true, nil)
            } else {
                mockDAO.On("ExistsByUsername", tt.req.Username).Return(false, nil)
                mockDAO.On("ExistsByPhone", tt.req.Phone).Return(false, nil)
                mockDAO.On("ExistsByEmail", tt.req.Email).Return(false, nil)
                mockDAO.On("Create", mock.Anything).Return(nil)
            }
            
            // 执行测试
            _, err := service.Register(tt.req)
            
            // 断言
            if tt.wantErr != nil {
                assert.Equal(t, tt.wantErr, err)
            } else {
                assert.NoError(t, err)
            }
        })
    }
}
```

```go
func TestUserAPI_Register(t *testing.T) {
    // 设置测试路由
    router := setupTestRouter()
    
    // 准备测试数据
    reqBody := `{
        "username": "testuser",
        "password": "Test@123456",
        "phone": "13800138000",
        "email": "test@example.com"
    }`
    
    // 创建请求
    req := httptest.NewRequest("POST", "/api/v1/users/register", 
        strings.NewReader(reqBody))
    req.Header.Set("Content-Type", "application/json")
    
    // 执行请求
    w := httptest.NewRecorder()
    router.ServeHTTP(w, req)
    
    // 断言响应
    assert.Equal(t, http.StatusOK, w.Code)
    
    var resp response.Response
    json.Unmarshal(w.Body.Bytes(), &resp)
    assert.Equal(t, 200, resp.Code)
    assert.Contains(t, resp.Message, "成功")
}
```

## 9. 测试最佳实践

### 9.1 命名规范

```go
// 测试函数命名: Test<StructName>_<MethodName>
func TestUserService_Register(t *testing.T) {}

// 基准测试命名: Benchmark<StructName>_<MethodName>
func BenchmarkUserService_Login(b *testing.B) {}

// 示例测试命名: Example<FunctionName>
func ExampleHashPassword() {}
```

### 9.2 测试结构

使用AAA模式（Arrange-Act-Assert）：

```go
func TestExample(t *testing.T) {
    // Arrange - 准备测试数据和环境
    db := setupTestDB(t)
    service := NewService(db)
    
    // Act - 执行被测试的操作
    result, err := service.DoSomething()
    
    // Assert - 验证结果
    assert.NoError(t, err)
    assert.Equal(t, expected, result)
}
```

### 9.3 表驱动测试

```go
func TestUserService_Register(t *testing.T) {
    tests := []struct {
        name    string
        input   *model.UserRegisterRequest
        wantErr error
    }{
        {
            name: "正常注册",
            input: &model.UserRegisterRequest{
                Username: "testuser",

```

## 10. CI/CD集成

### 10.1 GitHub Actions

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: test123
          MYSQL_DATABASE: pet_adoption_test
        ports:
          - 3306:3306
          
      redis:
        image: redis:7-alpine
        ports:
          - 6379:6379
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Go
        uses: actions/setup-go@v4
        with:
          go-version: '1.25'
      
      - name: Run tests
        run: |
          go test -v -coverprofile=coverage.out ./...
          go tool cover -func=coverage.out
      
      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.out
```
