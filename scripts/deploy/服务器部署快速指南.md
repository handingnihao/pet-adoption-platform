# 服务器部署快速指南

## 🎯 适用场景

- ✅ 服务器已安装 MySQL 8.4
- ✅ 有 root 权限
- ✅ 需要快速部署数据库

## ⚡ 5分钟快速部署

### 1️⃣ 准备工作（1分钟）

```bash
# 连接到服务器
ssh user@your-server-ip

# 创建工作目录
sudo mkdir -p /opt/pet-adoption/scripts
cd /opt/pet-adoption/scripts

# 上传脚本文件到此目录
# 需要上传的文件：
#   - 01_create_user_and_database.sql
#   - 02_create_tables.sql
#   - 03_init_data.sql
#   - deploy_database.sh (可选)
```

### 2️⃣ 一键部署（3分钟）

#### 方式A: 使用自动化脚本

```bash
# 赋予执行权限
chmod +x deploy_database.sh

# 执行部署
./deploy_database.sh

# 按提示输入：
# 1. MySQL root 密码
# 2. 确认部署 (y)
# 3. pet_admin 密码 (可直接回车使用默认)
# 4. 是否插入测试数据 (y)
```

#### 方式B: 手动执行

```bash
# 步骤1: 创建数据库和用户
mysql -u root -p < 01_create_user_and_database.sql
# 输入 root 密码

# 步骤2: 创建数据表
mysql -u pet_admin -p'Pet@Admin#2024!Secure' pet_adoption < 02_create_tables.sql

# 步骤3: 插入初始数据（可选）
mysql -u pet_admin -p'Pet@Admin#2024!Secure' pet_adoption < 03_init_data.sql
```

### 3️⃣ 验证部署（1分钟）

```bash
# 测试连接
mysql -u pet_admin -p'Pet@Admin#2024!Secure' pet_adoption

# 在 MySQL 中执行：
SHOW TABLES;
SELECT COUNT(*) FROM users;
EXIT;
```

如果看到 10 个表，说明部署成功！ 🎉


## 🔐 安全加固（重要！）

### 1. 修改数据库密码

```bash
mysql -u root -p

# 在 MySQL 中执行：
ALTER USER 'pet_admin'@'%' IDENTIFIED BY 'YourNewStrongPassword@2024';
ALTER USER 'pet_admin'@'localhost' IDENTIFIED BY 'YourNewStrongPassword@2024';
FLUSH PRIVILEGES;
EXIT;
```

### 2. 修改应用管理员密码

```bash
# 登录应用后台立即修改
# 默认账户：admin / Admin@123456
```

### 3. 配置防火墙

```bash
# Ubuntu/Debian
sudo ufw allow 3306/tcp  # 如果需要远程访问
sudo ufw allow 8080/tcp  # 应用端口
sudo ufw enable

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=3306/tcp
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

### 4. 限制 MySQL 访问（可选）

如果应用和数据库在同一服务器：

```bash
mysql -u root -p

# 删除远程用户，只保留本地
DROP USER 'pet_admin'@'%';
FLUSH PRIVILEGES;
EXIT;
```

然后修改 `config/config.yaml`:
```yaml
database:
  mysql:
    host: "localhost"  # 改为 localhost
```

## 📦 设置自动备份

### 创建备份脚本

```bash
# 创建备份目录
sudo mkdir -p /opt/pet-adoption/backups

# 创建备份脚本
sudo nano /opt/pet-adoption/backup.sh
```

粘贴以下内容：

```bash
#!/bin/bash
BACKUP_DIR="/opt/pet-adoption/backups"
DATE=$(date +%Y%m%d_%H%M%S)
PASSWORD="YourPassword"  # 修改为实际密码

# 备份数据库
mysqldump -u pet_admin -p"$PASSWORD" pet_adoption | gzip > "$BACKUP_DIR/pet_adoption_$DATE.sql.gz"

# 删除7天前的备份
find "$BACKUP_DIR" -name "*.sql.gz" -mtime +7 -delete

echo "Backup completed: pet_adoption_$DATE.sql.gz"
```

保存并设置权限：

```bash
sudo chmod +x /opt/pet-adoption/backup.sh
sudo chmod 700 /opt/pet-adoption/backup.sh  # 只有 root 可读写执行
```

### 设置定时任务

```bash
# 编辑 crontab
sudo crontab -e

# 添加以下行（每天凌晨2点备份）
0 2 * * * /opt/pet-adoption/backup.sh >> /var/log/pet_backup.log 2>&1
```

### 测试备份

```bash
# 手动运行备份
sudo /opt/pet-adoption/backup.sh

# 查看备份文件
ls -lh /opt/pet-adoption/backups/
```

## 🚀 启动应用

### 后台运行（使用 nohup）

```bash
cd /opt/pet-adoption
nohup ./server > app.log 2>&1 &

# 查看进程
ps aux | grep server

# 查看日志
tail -f app.log
```

### 使用 systemd（推荐）

创建服务文件：

```bash
sudo nano /etc/systemd/system/pet-adoption.service
```

内容：

```ini
[Unit]
Description=Pet Adoption Platform
After=network.target mysql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/pet-adoption
ExecStart=/opt/pet-adoption/server
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
# 重载配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start pet-adoption

# 设置开机自启
sudo systemctl enable pet-adoption

# 查看状态
sudo systemctl status pet-adoption

# 查看日志
sudo journalctl -u pet-adoption -f
```

## ❓ 故障排查

### 应用无法连接数据库

```bash
# 1. 检查 MySQL 是否运行
sudo systemctl status mysql

# 2. 检查用户权限
mysql -u root -p -e "SHOW GRANTS FOR 'pet_admin'@'%';"

# 3. 测试连接
mysql -u pet_admin -p pet_adoption -e "SELECT 1;"

# 4. 查看错误日志
sudo tail -f /var/log/mysql/error.log
```

### 端口被占用

```bash
# 查看端口占用
sudo netstat -tlnp | grep 8080

# 杀死进程
sudo kill -9 <PID>
```

### 内存不足

```bash
# 查看内存使用
free -h

# 优化 MySQL 配置
sudo nano /etc/mysql/my.cnf

# 减小 innodb_buffer_pool_size
# innodb_buffer_pool_size = 512M
```
