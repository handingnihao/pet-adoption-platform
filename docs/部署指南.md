## 1. 服务器环境准备

### 1.1 系统要求
- CentOS 7/8 或 Rocky Linux 8/9
- 最低配置：2核 CPU、4GB 内存、40GB 硬盘
- 推荐配置：4核 CPU、8GB 内存、100GB SSD

### 1.2 更新系统
```bash
sudo yum update -y
sudo yum install -y epel-release
sudo yum install -y wget curl git vim net-tools
```

### 1.3 配置防火墙
```bash
# 开放必要端口
sudo firewall-cmd --permanent --add-port=80/tcp    # HTTP
sudo firewall-cmd --permanent --add-port=443/tcp   # HTTPS
sudo firewall-cmd --permanent --add-port=8080/tcp  # 后端API（可选，生产环境建议关闭）
sudo firewall-cmd --reload
```

### 1.4 关闭 SELinux（可选，或正确配置）
```bash
# 临时关闭
sudo setenforce 0

# 永久关闭（需重启）
sudo sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config
```

## 2. 安装依赖服务

### 2.1 安装 MySQL 8.0
```bash
# 添加 MySQL 仓库
sudo yum install -y https://dev.mysql.com/get/mysql80-community-release-el7-5.noarch.rpm

# 安装 MySQL
sudo yum install -y mysql-community-server

# 启动并设置开机自启
sudo systemctl start mysqld
sudo systemctl enable mysqld

# 获取临时密码
sudo grep 'temporary password' /var/log/mysqld.log

# 安全配置（按提示设置root密码）
sudo mysql_secure_installation
```

#### 创建数据库和用户
```bash
mysql -u root -p
```

```sql
-- 创建数据库
CREATE DATABASE pet_adoption CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户并授权
CREATE USER 'pet_admin'@'localhost' IDENTIFIED BY 'YourStrongPassword123!';
GRANT ALL PRIVILEGES ON pet_adoption.* TO 'pet_admin'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 2.2 安装 Redis 7
```bash
# 安装 Redis
sudo yum install -y redis

# 或从源码安装最新版
wget https://download.redis.io/redis-stable.tar.gz
tar xzf redis-stable.tar.gz
cd redis-stable
make
sudo make install

# 启动并设置开机自启
sudo systemctl start redis
sudo systemctl enable redis

# 验证
redis-cli ping  # 应返回 PONG
```

### 2.3 安装 Go 1.21+
```bash
# 下载 Go
wget https://go.dev/dl/go1.21.5.linux-amd64.tar.gz

# 解压到 /usr/local
sudo tar -C /usr/local -xzf go1.21.5.linux-amd64.tar.gz

# 配置环境变量
echo 'export PATH=$PATH:/usr/local/go/bin' | sudo tee /etc/profile.d/go.sh
echo 'export GOPATH=$HOME/go' >> ~/.bashrc
echo 'export PATH=$PATH:$GOPATH/bin' >> ~/.bashrc
source ~/.bashrc

# 验证
go version
```

### 2.4 安装 Node.js 18+（用于构建前端）
```bash
# 使用 NodeSource 仓库
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs

# 验证
node -v
npm -v

# 安装 pnpm（可选）
npm install -g pnpm
```

### 2.5 安装 Nginx
```bash
sudo yum install -y nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

## 3. 部署后端服务

### 3.1 上传项目代码
```bash
# 方式1：使用 Git
cd /home
git clone https://gitee.com/your-username/pet-adoption-platform.git
cd pet-adoption-platform

# 方式2：使用 scp 从本地上传
# 在本地执行：
scp -r ./pet-adoption-platform root@your-server-ip:/home/
```

### 3.2 配置后端
```bash
cd /home/pet-adoption-platform

# 复制配置文件
cp config/config.yaml.example config/config.yaml

# 编辑配置文件
vim config/config.yaml
```

修改 `config/config.yaml`：
```yaml
server:
  host: "0.0.0.0"
  port: 8080
  mode: "release"  # 生产环境使用 release

database:
  mysql:
    host: "localhost"
    port: 3306
    username: "pet_admin"
    password: "YourStrongPassword123!"
    database: "pet_adoption"
    charset: "utf8mb4"
    max_idle_conns: 10
    max_open_conns: 100

redis:
  host: "localhost"
  port: 6379
  password: ""
  db: 0

jwt:
  secret: "your-very-long-and-secure-secret-key-change-this"
  expire_hours: 168

log:
  level: "info"
  filename: "logs/app.log"
  max_size: 100
  max_backups: 10
  max_age: 30
  compress: true
```

### 3.3 编译后端
```bash
cd /home/pet-adoption-platform

# 下载依赖
go mod tidy

# 编译（生产版本）
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o pet-server ./cmd/server

# 创建日志目录
mkdir -p logs
```

### 3.4 初始化数据库
```bash
# 运行数据库迁移（如果有）
./pet-server migrate

# 或手动导入 SQL（如果有 init.sql）
mysql -u pet_admin -p pet_adoption < scripts/init.sql
```

### 3.5 测试运行
```bash
./pet-server
# 访问 http://your-server-ip:8080/api/health 测试
# Ctrl+C 停止
```

## 4. 部署前端应用

### 4.1 构建前端
```bash
cd /home/pet-adoption-platform/web

# 安装依赖
npm install
# 或使用 pnpm
pnpm install

# 配置生产环境 API 地址
cat > .env.production << EOF
VITE_API_BASE_URL=/api
EOF

# 构建生产版本
npm run build
# 或
pnpm build
```

### 4.2 部署静态文件
```bash
# 将构建产物复制到 Nginx 目录
sudo mkdir -p /var/www/pet-adoption
sudo cp -r dist/* /var/www/pet-adoption/
sudo chown -R nginx:nginx /var/www/pet-adoption
```

## 5. 配置 Nginx

### 5.1 创建 Nginx 配置
```bash
sudo vim /etc/nginx/conf.d/pet-adoption.conf
```

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或 IP

    # 前端静态文件
    root /var/www/pet-adoption;
    index index.html;

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    gzip_min_length 1000;

    # 前端路由（SPA）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持（如需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### 5.2 测试并重载 Nginx
```bash
# 测试配置
sudo nginx -t

# 重载配置
sudo systemctl reload nginx
```

### 5.3 配置 HTTPS（推荐）
```bash
# 安装 Certbot
sudo yum install -y certbot python3-certbot-nginx

# 获取证书（需要域名已解析到服务器）
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 6. 配置 Systemd 服务

### 6.1 创建后端服务文件
```bash
sudo vim /etc/systemd/system/pet-server.service
```

```ini
[Unit]
Description=Pet Adoption Platform Backend
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/home/pet-adoption-platform
ExecStart=/home/pet-adoption-platform/pet-server
Restart=always
RestartSec=5
StandardOutput=append:/home/pet-adoption-platform/logs/stdout.log
StandardError=append:/home/pet-adoption-platform/logs/stderr.log

# 环境变量
Environment=GIN_MODE=release

[Install]
WantedBy=multi-user.target
```

### 6.2 启动服务
```bash
# 重载 systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start pet-server

# 设置开机自启
sudo systemctl enable pet-server

# 查看状态
sudo systemctl status pet-server

# 查看日志
sudo journalctl -u pet-server -f
```

### 6.3 常用命令
```bash
# 重启服务
sudo systemctl restart pet-server

# 停止服务
sudo systemctl stop pet-server

# 查看日志
tail -f /home/pet-adoption-platform/logs/app.log
```

## 7. 常见问题

### 7.1 端口被占用
```bash
# 查看端口占用
netstat -tlnp | grep 8080
# 或
lsof -i :8080

# 杀死占用进程
kill -9 <PID>
```

### 7.2 MySQL 连接失败
```bash
# 检查 MySQL 状态
sudo systemctl status mysqld

# 检查连接
mysql -u pet_admin -p -h localhost pet_adoption

# 查看错误日志
sudo tail -f /var/log/mysqld.log
```

### 7.3 Redis 连接失败
```bash
# 检查 Redis 状态
sudo systemctl status redis
redis-cli ping
```

### 7.4 Nginx 502 Bad Gateway
```bash
# 检查后端是否运行
curl http://127.0.0.1:8080/api/health

# 检查 Nginx 错误日志
sudo tail -f /var/log/nginx/error.log
```

### 7.5 权限问题
```bash
# 修复文件权限
sudo chown -R root:root /home/pet-adoption-platform
sudo chmod +x /home/pet-adoption-platform/pet-server
```

### 7.6 更新部署
```bash
cd /home/pet-adoption-platform

# 拉取最新代码
git pull origin main

# 重新编译后端
go build -ldflags="-s -w" -o pet-server ./cmd/server

# 重新构建前端
cd web && npm run build
sudo cp -r dist/* /var/www/pet-adoption/

# 重启服务
sudo systemctl restart pet-server
```

## 快速部署脚本

创建一键部署脚本 `deploy.sh`：
```bash
#!/bin/bash
set -e

echo ">>> 拉取最新代码..."
git pull origin main

echo ">>> 编译后端..."
go build -ldflags="-s -w" -o pet-server ./cmd/server

echo ">>> 构建前端..."
cd web
npm install
npm run build
sudo cp -r dist/* /var/www/pet-adoption/
cd ..

echo ">>> 重启服务..."
sudo systemctl restart pet-server

echo ">>> 部署完成!"
```

```bash
chmod +x deploy.sh
./deploy.sh
```
