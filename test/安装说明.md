# 前端测试环境安装说明

## 安装步骤

### 1. 进入前端目录

```bash
cd web
```

### 2. 安装测试依赖

```bash
npm install
```

这将安装以下测试相关的依赖包：

- `vitest` - 单元测试框架
- `@vitest/ui` - Vitest UI界面
- `@vitest/coverage-v8` - 代码覆盖率工具
- `@testing-library/react` - React组件测试工具
- `@testing-library/jest-dom` - DOM断言扩展
- `@testing-library/user-event` - 用户事件模拟
- `jsdom` - DOM环境模拟
- `@playwright/test` - E2E测试框架

### 3. 安装Playwright浏览器（仅E2E测试需要）

```bash
npx playwright install
```

这将下载Chromium、Firefox和WebKit浏览器。

如果只需要Chromium：

```bash
npx playwright install chromium
```

## 验证安装

### 运行单元测试

```bash
npm run test:run
```

如果看到测试通过，说明安装成功！

### 运行E2E测试

```bash
# 确保前端服务正在运行
npm run dev

# 在另一个终端运行E2E测试
npm run test:e2e
```

## 常见问题

### Q: npm install 很慢怎么办？

A: 可以使用国内镜像：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q: Playwright安装失败？

A: 可以设置环境变量使用国内镜像：

```bash
# Windows PowerShell
$env:PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright/"
npx playwright install

# Linux/Mac
export PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/
npx playwright install
```

### Q: 测试运行失败？

A: 检查：
1. Node.js版本是否 >= 18
2. 依赖是否完整安装
3. 查看错误日志定位问题
