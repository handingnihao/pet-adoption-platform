# 爱心宠物领养平台 - 系统架构图

## 1. 系统整体架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         前端层 (Web)                              │
│  React 18 + TypeScript + Vite + TailwindCSS + shadcn/ui        │
├─────────────────────────────────────────────────────────────────┤
│                         HTTP/HTTPS                               │
├─────────────────────────────────────────────────────────────────┤
│                      后端层 (Backend)                             │
│              Go 1.25 + Gin + GORM + JWT                         │
│  ┌──────────────┬──────────────┬──────────────┬──────────────┐ │
│  │   Router     │  Controller  │   Service    │     DAO      │ │
│  │   (路由层)    │  (控制器层)   │  (业务层)     │  (数据访问层) │ │
│  └──────────────┴──────────────┴──────────────┴──────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│                      中间件层 (Middleware)                        │
│    CORS │ Logger │ Auth │ RateLimit │ Recovery                 │
├─────────────────────────────────────────────────────────────────┤
│                      公共包层 (Pkg)                               │
│  Database │ Cache │ Logger │ Utils │ Response                  │
├─────────────────────────────────────────────────────────────────┤
│                      数据层 (Data)                                │
│  ┌──────────────────────┬──────────────────────┐               │
│  │   MySQL 8.0+         │    Redis 7.0+        │               │
│  │   (关系型数据库)       │    (缓存数据库)       │               │
│  └──────────────────────┴──────────────────────┘               │
└─────────────────────────────────────────────────────────────────┘
```
